Koneksi Database Cloud (Supabase)

Secara default, perubahan stok otomatis tersimpan di Local Backend (`server/index.js`) & Browser Storage. Jika ingin di-deploy ke Vercel agar stok tersimpan di Cloud, masukkan URL & Anon Key project Supabase kamu di bawah:

SQL Setup Tabel Supabase (Jalankan 1x di SQL Editor Supabase): 
create table if not exists public.products (
  id bigint primary key,
  name text not null,
  type text not null,
  category text,
  "basePricePerKg" numeric not null default 0,
  "stockKg" numeric not null default 0,
  "produceId" text,
  desc text,
  image text,
  featured boolean default false
);
alter table public.products enable row level security;
create policy "Public read products" on public.products for select using (true);
create policy "Public write products" on public.products for all using (true) with check (true);
